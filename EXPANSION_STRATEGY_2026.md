## ⚠️ RISKS & MITIGATION

### Risk: Search API Rate Limiting
```
Problem: Google Places API throttles at 10K calls/day
Impact: Can't discover fast enough
Mitigation: 
  - Distribute geospatial search across regions
  - Implement exponential backoff + queue
  - Cache previous searches by territory
```

### Risk: Stitch Generation Bottleneck
```
Problem: Stitch MCP might be slow (30s per demo)
Impact: Can't generate 5K demos in month
Mitigation:
  - Parallel generation workers
  - Caching of common templates
  - Hybrid: Pre-generated templates for speed, custom for quality
```

### Risk: Email Deliverability
```
Problem: Spam folder at scale (high volume from single domain)
Impact: Open rates drop below 10%
Mitigation:
  - Rotate through multiple sending domains
  - Warm up each domain gradually
  - Use Resend's reputation management
  - Personalization (not "mass mail" look)
```

### Risk: Competitor Response
```
Problem: Other companies copy the model
Impact: Commoditization of service
Mitigation:
  - Build proprietary data moat (industry knowledge)
  - Own the relationship (customer lock-in)
  - Continuous innovation (always be ahead)
```
