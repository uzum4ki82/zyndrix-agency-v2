# 🚀 Zyndrix Commander: Intelligence & Outreach Engine

Zyndrix Commander is a high-performance, AI-driven lead generation and automated outreach platform. It specializes in hyper-local market penetration using deep intelligence agents.

## 🛠 Tech Stack
- **Framework**: Next.js 15+ (App Router)
- **Database**: Supabase (PostgreSQL)
- **Agents**: Custom Agentic Brain (`Hunter`, `Strategist`, `Copywriter`, `Designer`)
- **Outreach**: Resend API
- **Maps Intelligence**: Google Places API (Text Search)
- **Styling**: Vanilla CSS (High-Performance/Minimalist)

## 📍 Target Focus: Sant Antoni de Vilamajor
The engine is currently tuned for aggressive penetration in Sant Antoni de Vilamajor and surrounding areas (Les Pungoles, Alfou, Can Vila).

## 🚀 Key Features
- **Auto-TIER Classification**: Detects businesses without web (TIER 1), social media only (TIER 2), and standard web (TIER 3).
- **Automated Intelligence**: Generates strategic insights and financial impact projections for each lead.
- **Dynamic Proposals**: Tailors the pitch based on the lead's digital maturity level.
- **Glassmorphic UI**: Premium "Architectural Luxury" dashboard for executive monitoring.
